### What I did

* Loaded the Bank Marketing dataset
* Separated the features and target
* Converted categorical values into numerical values
* Split the data into 80% training and 20% testing
* Scaled the features using StandardScaler
* Applied Logistic Regression
* Predicted the test data
* Checked the accuracy
* Also calculated confusion matrix, precision, recall and F1-score
